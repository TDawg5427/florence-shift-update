# Florence Shift Update Mobile v1.3.1

## Theme update
- Switched the app to a dark theme.
- Main colors are now:
  - Black / near-black backgrounds
  - Dark blue cards and surfaces
  - White text
  - Light blue accents
- Kept the redesigned layout from v1.3.0, just with a darker, sleeker look.

## Functionality preserved
All current features remain:
- Rooms Ran / Escapes
- `No rooms` when both are 0
- Repeatable Walk-Ins and Rebookings
- Individual employee milestones at 5 / 10
- Cash and Square entries with time, room, and purchase
- Weekly checklist worked / finished
- Deep clean checkboxes
- Late starts
- Exclusions
- Merch
- Training
- Shoutouts
- Notes
- Copy Shift Update

## Updating GitHub Pages
Replace all files in the existing repository with the files from this folder.

Then open:
`https://YOURUSERNAME.github.io/YOURREPOSITORY/?v=1.3.1`

You should see `v1.3.1` in the top-right corner.

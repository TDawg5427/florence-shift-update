# Florence Shift Update Mobile v1.2.2

## Changes
- Walk-In milestones now belong to each individual employee entry.
- Rebooking milestones now belong to each individual employee entry.
- Each Walk-In/Rebooking entry has:
  - Employee
  - Count
  - At 5 checkbox
  - At 10 checkbox
- Checking At 10 automatically checks At 5.
- The Slack output keeps the milestone on the same employee line.

Examples:
- `1 WI via JP - JP is at 5`
- `2 rebookings via Izzy - Izzy is at 10`

There is no separate Walk-In Milestones or Rebooking Milestones section anymore.

## Updating GitHub Pages
Replace all files in your existing repository with the files from this folder.

Then open:
`https://YOURUSERNAME.github.io/YOURREPOSITORY/?v=1.2.2`

You should see `v1.2.2` in the top-right corner.

# Florence Shift Update Mobile v1.3.0

## Visual redesign
- Switched from a dark dashboard to a light pastel iPhone-style design.
- New lavender / blue / pink / peach / mint accent system.
- New top banner with floating decorative bubbles.
- Numbered section badges for easier scanning.
- Softer cards, rounded inputs, cleaner checkboxes, and pill-style buttons.
- Redesigned empty states and Slack preview area.
- Mobile spacing adjusted for iPhone screens.

## Functionality preserved
All v1.2.3 features remain:
- Rooms Ran / Escapes
- `No rooms` when both are 0
- Repeatable Walk-Ins and Rebookings
- Individual employee milestones at 5 / 10
- Cash and Square entries with time, room, and purchase
- Weekly checklist worked / finished
- Deep clean checkboxes
- Late starts
- Exclusions
- Merch
- Training
- Shoutouts
- Notes
- Copy Shift Update

## Updating GitHub Pages
Replace all files in the existing repository with the files from this folder.

Then open:
`https://YOURUSERNAME.github.io/YOURREPOSITORY/?v=1.3.0`

You should see `v1.3.0` in the top-right corner.
